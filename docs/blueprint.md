# **App Name**: Aura Chat

## Core Features:

- Real-Time Chat: Enable users to exchange messages in real-time with typing indicators and message delivery status.
- User Authentication: Secure user accounts with login/signup functionality.
- Chat Room Creation: Allow users to create and join different chat rooms or channels.
- Direct Messaging: Enable private one-on-one conversations between users.
- Message History: Store and display previous chat messages within each chat room and direct message.
- AI-Powered Message Summarization: An AI tool provides users with the ability to summarize conversations.
- User Profile: Allow users to create and update their profile information, including age, gender, and other details.
- User Search: Enable users to search for other users and add them as contacts.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082), creating a sense of sophistication and innovation.
- Background color: Very dark desaturated Indigo (#1A1324), providing a clean, modern backdrop that emphasizes content.
- Accent color: Electric Violet (#8F00FF), drawing attention to key elements.
- Font: 'Inter', a sans-serif font for both headings and body text.
- Minimalist and consistent icons for navigation and actions.
- Clean, modern layout with a focus on readability and user experience.
- Subtle transitions and animations for a smooth user experience.
